v3: Logit-Lens Causal Tracing

Runs a pure-numpy forward pass on the GGUF and projects hidden states through the lm_head at each layer. Finds the earliest layer where each fact's answer appears in top-K predictions. No inference backend required — works directly on weights.

Requires Llama-architecture with full attn + MLP tensors (attn_q/k/v/output, ffn_gate/up/down, attn_norm, ffn_norm, output_norm, output).

v3: ROME Rank-1 Fact Editing

Overwrites specific factual associations in the model's MLP weights — without retraining. Uses the ROME algorithm: finds the layer+neuron storing a fact, then applies a rank-1 update to W_down that replaces the stored value with a new target.

The modified GGUF is saved as a new file. The original is never modified.
